## 📊 Функционал дашборда

### Ключевые метрики (Cards)
```
┌─────────────┬─────────────┬─────────────┬─────────────┐
│ 👥 Users    │ 📋 Tasks    │ 💰 GMV      │ 🟢 Online   │
│ 9           │ 13          │ 33K ₽       │ 2           │
│ +9 за неделю│ +13 за нед. │             │             │
└─────────────┴─────────────┴─────────────┴─────────────┘
```

### Графики
- **📈 Рост пользователей** - линейный график за 7 дней
- **💵 Доход (комиссия)** - линейный график за 7 дней
- **📊 Задачи по категориям** - столбчатая диаграмма

### Очереди (требуют внимания)
```
┌──────────────────────────────────────────┐
│ ⚖️  1 спор ждет решения                  │
│ ✅  0 заявок на верификацию              │
│ 💸  1 вывод на рассмотрении              │
└──────────────────────────────────────────┘
```

### Вкладки

**📊 Обзор**:
- Детальная финансовая статистика
- Разбивка пользователей (заказчики, специалисты, PRO, верифицированные)
- Статистика задач (по статусам)

**👥 Пользователи**:
- Таблица всех пользователей
- Фильтры: по роли, верификации, PRO статусу
- Поиск по email и имени
- Пагинация (20 записей на страницу)

**⚡ Активность**:
- Новые пользователи (10 последних)
- Новые задачи (10 последних)
- Крупные транзакции (10 последних)

## 🎯 Проверка работы

### 1. Статистика загружается
```bash
curl -H "Authorization: Bearer <TOKEN>" http://localhost:8000/admin/stats | python -m json.tool
```

Ожидается:
```json
{
  "users": { "total": 9, "online": 2, ... },
  "tasks": { "total": 13, ... },
  "money": { "gmv": 33000, ... },
  "charts": { ... }
}
```

### 2. Активность отображается
```bash
curl -H "Authorization: Bearer <TOKEN>" http://localhost:8000/admin/recent-activity
```

### 3. Пользователи фильтруются
```bash
curl -H "Authorization: Bearer <TOKEN>" "http://localhost:8000/admin/users?role=specialist&verified=true"
```

## 🔐 Безопасность

### Проверка прав:
1. Backend проверяет `ADMIN_EMAILS` через `is_admin(user)`
2. Frontend проверяет email в навигации
3. При попытке доступа без прав → экран "Доступ запрещён"

### Добавление нового админа:
```bash
# В .env добавьте email
ADMIN_EMAILS=admin@delo.ru,new_admin@delo.ru
```
