## Как это работает:

### 1. Пополнение баланса (реальные деньги):

**Старый способ (демо):**
- Нажать "Пополнить" → ввести сумму → деньги появляются мгновенно
- ❌ Нереальные деньги, только для разработки

**Новый способ (ЮMoney):**
- Нажать "Пополнить" → ввести сумму (минимум 100 ₽)
- Откроется форма оплаты ЮMoney в новом окне
- Оплатить банковской картой или из кошелька ЮMoney
- Вернуться в приложение → нажать "Проверить статус платежа"
- ✅ Деньги зачисляются на баланс

### 2. Покупка пакетов (PRO, отклики):

Работает через внутренний баланс:
- Деньги списываются с баланса пользователя
- Зачисляются кредиты/подписка
- **Реальные деньги** если баланс пополнен через ЮMoney

### 3. Вывод средств:

Сейчас работает через админ-панель:
- Пользователь создает заявку на вывод
- Админ проверяет и одобряет
- Админ вручную переводит деньги (карта/СБП)
- В будущем можно автоматизировать через ЮMoney API

## Тестирование (Ctrl+F5 чтобы обновить):

### Тест 1: Проверка статуса API

```bash
curl http://localhost:8000/payments/status
```

Ожидаемый ответ:
```json
{
  "yookassa": {"configured": false},
  "yoomoney": {"configured": true}
}
```

### Тест 2: Создание платежа

1. Откройте приложение в браузере
2. Войдите в профиль
3. Нажмите "Пополнить"
4. Введите сумму (например, 500 ₽)
5. Нажмите "Перейти к оплате"
6. Должно открыться окно ЮMoney с формой оплаты

### Тест 3: Реальная оплата (ОСТОРОЖНО - реальные деньги!)

**Только для production тестов:**
1. В форме ЮMoney введите реальную карту
2. Завершите оплату
3. Вернитесь в приложение
4. Нажмите "Проверить статус платежа"
5. Баланс должен пополниться

**Для dev тестов без реальных денег:**
- Используйте демо-endpoint `/wallet/deposit` (работает только на dev)
- Или создайте тестовый кошелек ЮMoney с минимальным балансом

## FAQ:

**Q: Можно ли использовать демо-пополнение на production?**
A: Нет, оно отключено через `settings.IS_PRODUCTION`. На production работает только ЮMoney.

**Q: Сколько стоит прием платежей?**
A: ЮMoney берет ~2% + 15₽ с каждого платежа картой.

**Q: Можно ли протестировать без реальных денег?**
A: Да, используйте `/wallet/deposit` на dev окружении или пополните тестовый кошелек ЮMoney на минимальную сумму.

**Q: Что делать если платеж не зачислился?**
A: Проверьте:
1. Платеж успешен в ЮMoney (зайдите в кошелек)
2. Backend логи: `tail -f backend.log | grep payment`
3. Попробуйте нажать "Проверить статус" еще раз

**Q: Работает ли автоматическое зачисление?**
A: Да, если настроен вебхук. Без вебхука пользователь должен вручную нажать "Проверить статус".
