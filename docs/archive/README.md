# Архив

Отчёты, статусы и инструкции прошлых этапов разработки (сентябрь 2026).
Они сохранены для истории и **могут не соответствовать текущему коду**:
ссылки внутри них и описанные шаги не поддерживаются.

Актуальная документация — в [README](../../README.md) и в папке [docs](..).

В `legacy/` лежат старые скрипты и конфиги прежней схемы развёртывания
(nginx + systemd под домен delomaster.online). Не используйте их на текущем
сервере: они конфликтуют с Caddy за порты 80/443.
