# Тестирование функций аватара и портфолио

## Приложение запущено:
- Backend: http://localhost:8000
- Frontend: http://localhost:3001
- API Docs: http://localhost:8000/docs

---

## Тест 1: Загрузка аватара

### Шаги:
1. Открыть http://localhost:3001
2. Войти в аккаунт (или зарегистрироваться)
3. Перейти в Профиль
4. Нажать "Редактировать профиль"
5. В разделе "Фото профиля" нажать "Загрузить аватар"
6. Выбрать изображение (jpg, png, макс 5MB)
7. Появится preview с кнопками "Сохранить" и "Отмена"
8. Нажать "Сохранить"

### Ожидаемый результат:
- ✅ Toast уведомление: "Аватар обновлен!"
- ✅ Аватар отображается в header приложения
- ✅ Аватар отображается в профиле

### Если не работает:
Откройте DevTools (F12) → Console и проверьте ошибки

---

## Тест 2: Удаление аватара

### Шаги:
1. После загрузки аватара
2. В разделе "Фото профиля" появится красная кнопка "Удалить"
3. Нажать "Удалить"

### Ожидаемый результат:
- ✅ Toast уведомление: "Аватар удален"
- ✅ Вместо аватара показываются инициалы на цветном фоне

## Тест 3: Отмена загрузки

### Шаги:
1. Нажать "Загрузить аватар"
2. Выбрать файл → появляется preview
3. Нажать "Отмена"

### Ожидаемый результат:
- ✅ Preview исчезает
- ✅ Текущий аватар не изменяется

## Тест 4: Удаление фото из портфолио (только для специалистов)

### Шаги:
1. Переключиться на роль "Специалист" (если вы заказчик)
2. В профиле прокрутить до секции "Портфолио"
3. Нажать "Добавить работу"
4. Выбрать изображение
5. После загрузки навести курсор на фото
6. Появится кнопка ✕ в правом верхнем углу
7. Нажать ✕

### Ожидаемый результат:
- ✅ Toast уведомление: "Работа удалена из портфолио"
- ✅ Фото исчезает из портфолио

## Отладка

### Если аватар не сохраняется:

1. **Проверить console в DevTools**:
   - Открыть F12 → Console
   - Искать ошибки (красный текст)
   - Проверить Network tab → найти запрос PUT /users/me
   - Посмотреть Response

2. **Проверить backend логи**:
```bash
cat backend.log | tail -50
```

3. **Проверить размер файла**:
   - Максимум 5MB
   - Только изображения (jpg, png, gif, webp)

4. **Проверить формат base64**:
   - Должен начинаться с `data:image/...;base64,...`
   - Avatar.jsx автоматически конвертирует в правильный формат

### Если кнопка "Удалить" не появляется:

1. **Проверить что аватар загружен**:
```javascript
// В DevTools Console:
JSON.parse(localStorage.getItem('auth-storage')).state.user.avatar
// Должно вернуть base64 строку или URL
```

2. **Проверить компонент**:
   - В Avatar.jsx строка 142: `{currentAvatar && ...}`
   - currentAvatar должен быть truthy

## Частые проблемы

### Проблема: "Аватар загружается, но не отображается"
**Решение**: Обновить страницу (Ctrl+R) - иногда нужна перезагрузка компонента

### Проблема: "Кнопка загрузки не реагирует"
**Решение**: Проверить что `token` передан в компонент AvatarUploader

### Проблема: "Backend возвращает 401 Unauthorized"
**Решение**: Токен истёк, нужно перелогиниться

### Проблема: "Backend возвращает 422 Validation Error"
**Решение**: 
- Проверить что avatar это строка (base64) или null
- Проверить что base64 валидный
