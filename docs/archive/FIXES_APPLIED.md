### ✅ 1. Исправлена несовместимость типов для `last_seen`

**Проблема**: Модель ожидала `DateTime`, но записывалась строка через `.isoformat()`

**Исправлено в файлах**:

```python
db.query(User).filter(User.id == uid).update({"last_seen": now.isoformat()})
```

```python
db.query(User).filter(User.id == uid).update({"last_seen": now})  # datetime объект
```

## 🟡 Средние исправления (3/3)

### ✅ 4. Заменен устаревший `datetime.utcnow()`

**Проблема**: `datetime.utcnow()` deprecated в Python 3.12+

**Исправлено в файлах**:
- `backend/main.py` - 3 вхождения
- `backend/app/api/auth.py` - 4 вхождения
- `backend/app/api/users.py` - 1 вхождение
- `backend/app/core/security.py` - 3 вхождения

**Замена**:
```python
# Было:
datetime.utcnow()

# Стало:
datetime.now(timezone.utc)
```

**Осталось**: 13 вхождений в других файлах (не критично, можно исправить позже)

**Результат**: ✅ Совместимость с Python 3.12+
