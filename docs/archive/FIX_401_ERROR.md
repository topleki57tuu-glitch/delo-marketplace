# Инструкция: Решение проблемы 401 Unauthorized

## ❌ Проблема:
```
Failed to load resource: the server responded with a status of 401 (Unauthorized)
```

Это означает, что токен авторизации истёк или невалиден.

---

## ✅ Решение:

### Шаг 1: Очистить старые данные

1. **Откройте** http://localhost:3001
2. **Нажмите F12** (откроется DevTools)
3. **Перейдите** на вкладку **Application**
4. **Слева найдите** "Local Storage" → "http://localhost:3001"
5. **Найдите ключ** `auth-storage` или `auth`
6. **Нажмите правой кнопкой** → "Delete"
7. **Обновите страницу** (F5 или Ctrl+R)

---

### Шаг 2: Войти заново

1. Вы должны увидеть форму входа
2. Введите email и пароль
3. Нажмите "Войти"

---

### Шаг 3: Проверить что токен обновился

1. **F12** → **Console**
2. **Выполните**:
   ```javascript
   JSON.parse(localStorage.getItem('auth-storage')).state.token
   ```
3. **Должна вернуться строка**, начинающаяся с `eyJ...`
4. Если вернулся токен - всё ОК!

---

### Шаг 4: Теперь попробуйте загрузить аватар

1. Перейдите в **Профиль**
2. **"Редактировать профиль"**
3. **"Загрузить аватар"** → выберите фото → **"Сохранить"**

---

## 🔍 Если ошибка 401 повторяется:

### Проверка 1: Backend работает?
```bash
curl http://localhost:8000/docs
```
Должна открыться страница Swagger UI.

### Проверка 2: Проверить логи backend
```bash
cat backend.log | tail -50
```

### Проверка 3: Проверить что email/пароль правильные
Попробуйте зарегистрировать новый аккаунт:
1. Нажмите "Регистрация"
2. Введите новый email
3. Придумайте пароль (минимум 8 символов, хотя бы 1 цифра)
4. Войдите с новым аккаунтом

---

## 📝 Дополнительно: Почему истекает токен?

Токен JWT имеет время жизни (обычно 24 часа или 7 дней). После этого нужно входить заново.

**Наши исправления сегодня:**
- ✅ При переключении роли теперь выдаётся новый токен
- ✅ При обновлении профиля `db.refresh(user)` обновляет данные
- ✅ `onAvatarUpdate()` перезагружает профиль после сохранения

---
