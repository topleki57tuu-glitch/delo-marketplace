# 🚀 BAT файлы для управления приложением

## 📋 Описание

Набор BAT файлов для удобного запуска, остановки и управления приложением ДЕЛО Marketplace на Windows.

---

## 🎯 Доступные команды

### 1. `start.bat` - Запуск приложения

**Что делает:**
- ✅ Проверяет и освобождает порты 8000 и 3000
- ✅ Останавливает старые процессы (uvicorn, node)
- ✅ Запускает Backend (FastAPI) на порту 8000
- ✅ Запускает Frontend (Vite + React) на порту 3000
- ✅ Проверяет работоспособность сервисов
- ✅ Автоматически открывает браузер с приложением

**Использование:**
```cmd
start.bat
```

**Результат:**
- Backend: http://localhost:8000
- Frontend: http://localhost:3000
- API Docs: http://localhost:8000/docs
- Admin: http://localhost:3000/admin/dashboard

---

### 2. `stop.bat` - Остановка приложения

**Что делает:**
- ✅ Останавливает все процессы Backend (uvicorn, python)
- ✅ Останавливает все процессы Frontend (node)
- ✅ Освобождает порты 8000 и 3000
- ✅ Удаляет временные PID файлы
- ✅ Проверяет что порты освобождены

**Использование:**
```cmd
stop.bat
```

**Когда использовать:**
- Перед выключением компьютера
- При зависании приложения
- Для полной остановки всех процессов
- Перед обновлением кода

---

### 3. `restart.bat` - Перезапуск приложения

**Что делает:**
- ✅ Вызывает stop.bat (остановка)
- ✅ Ждет 2 секунды
- ✅ Вызывает start.bat (запуск)

**Использование:**
```cmd
restart.bat
```

**Когда использовать:**
- После изменения кода
- При багах или зависаниях
- После обновления зависимостей

---

### 4. `open-admin.bat` - Открыть Admin Dashboard

**Что делает:**
- ✅ Проверяет что Backend и Frontend запущены
- ✅ Открывает браузер с Admin Dashboard
- ✅ Показывает учетные данные для входа

**Использование:**
```cmd
open-admin.bat
```

**Требования:**
- Приложение должно быть запущено (start.bat)

**Учетные данные:**
- Email: `admin@delo.ru`
- Пароль: см. backend/demo_password.txt

---

### 5. `status.bat` - Статус приложения

**Что делает:**
- ✅ Проверяет работает ли Backend
- ✅ Проверяет работает ли Frontend
- ✅ Показывает занятые порты и PID процессов
- ✅ Показывает запущенные процессы
- ✅ Проверяет наличие базы данных
- ✅ Показывает размер файлов логов

**Использование:**
```cmd
status.bat
```

**Пример вывода:**

## 🔧 Типичные сценарии

### Первый запуск
```cmd
1. Дважды кликните start.bat
2. Дождитесь открытия браузера
3. Войдите в систему
```

### Ежедневная работа
```cmd
Утром:  start.bat
Вечером: stop.bat
```

### Открыть админку
```cmd
1. open-admin.bat
2. Войдите как admin@delo.ru
```

### При проблемах
```cmd
1. status.bat (проверить что не работает)
2. stop.bat (остановить всё)
3. start.bat (запустить заново)
```

### После изменения кода
```cmd
restart.bat
```

## 🐛 Решение проблем

### Проблема: "Порт занят"

**Решение:**
```cmd
stop.bat
```
Если не помогло:
```cmd
netstat -ano | findstr ":8000"
taskkill /F /PID <PID из вывода>
```

### Проблема: "Backend не отвечает"

**Решение:**
1. Проверьте логи: `backend\backend.log`
2. Перезапустите: `restart.bat`
3. Проверьте статус: `status.bat`

### Проблема: "Frontend не отвечает"

**Решение:**
1. Проверьте логи: `frontend\frontend.log`
2. Перезапустите: `restart.bat`
3. Проверьте статус: `status.bat`

### Проблема: "База данных не найдена"

**Решение:**
```cmd
cd backend
python seed_demo.py
cd ..
start.bat
```

### Проблема: Процессы не останавливаются

**Решение (ручная остановка):**
```cmd
taskkill /F /IM uvicorn.exe
taskkill /F /IM node.exe
taskkill /F /IM python.exe
```

## ⚙️ Настройка

### Изменить порты

**Backend (8000 → 8080):**
1. Откройте `start.bat`
2. Найдите `--port 8000`
3. Замените на `--port 8080`
4. Обновите `backend/.env`: `PORT=8080`

**Frontend (3000 → 3001):**
1. Откройте `start.bat`
2. Найдите все упоминания `3000`
3. Замените на `3001`
4. Обновите `frontend/vite.config.js`: `port: 3001`

## 📝 Примечания

1. **Не закрывайте окно** после запуска start.bat - процессы работают в фоне
2. **Всегда используйте stop.bat** для остановки, не закрывайте окна силой
3. **Проверяйте логи** если что-то не работает
4. **Используйте status.bat** для диагностики проблем
5. **Порты 8000 и 3000** должны быть свободны перед запуском
