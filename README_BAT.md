# 🚀 Быстрый старт - BAT файлы

## Управление приложением одним кликом

### 📋 Доступные команды

| Файл | Описание | Использование |
|------|----------|---------------|
| **start.bat** | Запустить приложение | Двойной клик |
| **stop.bat** | Остановить приложение | Двойной клик |
| **restart.bat** | Перезапустить | Двойной клик |
| **open-admin.bat** | Открыть админ панель | Двойной клик |
| **status.bat** | Проверить статус | Двойной клик |

---

## 🎯 Быстрое использование

### Первый запуск
1. Дважды кликните **`start.bat`**
2. Дождитесь открытия браузера
3. Готово! ✅

### Остановка
1. Дважды кликните **`stop.bat`**
2. Готово! ✅

### Открыть админку
1. Дважды кликните **`open-admin.bat`**
2. Войдите: `admin@delo.ru`
3. Готово! ✅
