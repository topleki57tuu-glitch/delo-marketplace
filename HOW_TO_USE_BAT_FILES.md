# ✅ BAT файлы готовы к использованию!

## 🚀 Как использовать

### ⚠️ ВАЖНО: Запускайте через проводник Windows, НЕ через bash/terminal!

1. Откройте **Проводник Windows** (File Explorer)
2. Перейдите в папку: `C:\Users\armen\delo-marketplace\`
3. Найдите BAT файлы
4. **Дважды кликните** на нужный файл

---

## 📋 Доступные файлы

### 1️⃣ start.bat - Запуск приложения
- **Что делает**: Запускает Backend + Frontend + открывает браузер
- **Как использовать**: Дважды кликните на `start.bat`
- **Результат**: Откроется окно с логами и браузер с приложением

### 2️⃣ stop.bat - Остановка приложения
- **Что делает**: Останавливает все процессы и освобождает порты
- **Как использовать**: Дважды кликните на `stop.bat`
- **Результат**: Все процессы остановлены

### 3️⃣ restart.bat - Перезапуск
- **Что делает**: Останавливает и снова запускает приложение
- **Как использовать**: Дважды кликните на `restart.bat`

### 4️⃣ open-admin.bat - Открыть админ панель
- **Что делает**: Открывает админ дашборд в браузере
- **Как использовать**: Дважды кликните на `open-admin.bat`
- **Логин**: admin@delo.ru / demo123

### 5️⃣ status.bat - Проверить статус
- **Что делает**: Показывает статус Backend, Frontend, портов, процессов
- **Как использовать**: Дважды кликните на `status.bat`

---

## 🎯 Пошаговая инструкция для первого запуска

1. Откройте **Проводник** (Win + E)
2. В адресной строке введите: `C:\Users\armen\delo-marketplace\`
3. Нажмите Enter
4. Найдите файл **start.bat**
5. **Дважды кликните** на него
6. Дождитесь открытия браузера
7. Войдите в систему или начните работу

---

## ❌ НЕ запускайте через:
- ❌ Git Bash
- ❌ WSL
- ❌ PowerShell (можно, но лучше через проводник)
- ❌ CMD (можно, но лучше через проводник)

## ✅ Запускайте:
- ✅ **Двойной клик в проводнике Windows** (рекомендуется)
- ✅ Правой кнопкой → "Открыть"

## 🐛 Если что-то не работает:

1. Запустите **status.bat** - посмотрите что не запущено
2. Запустите **stop.bat** - остановите всё
3. Запустите **start.bat** - запустите заново
